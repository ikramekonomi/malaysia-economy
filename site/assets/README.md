# Site assets

- `ikram-logo-original.jpeg`: IKRAM's logo as supplied (500×500).
- `ikram-logo.png` (192×192) and `favicon.png` (64×64): made from it. The sidebar shows `ikram-logo.png` on a white tile in both themes; the browser tab uses `favicon.png`.

To change the logo, replace `ikram-logo.png` and `favicon.png` (square, at least 76×76 px).
