# Site assets

- `ikram-logo-original.jpeg`: IKRAM's logo as supplied (500×500, white background).
- `ikram-logo-transparent.png`: the same logo with its background made transparent (full size).
- `ikram-logo.png` (192×192) and `favicon.png` (64×64): made from the transparent one, for the sidebar and the
  browser tab.

To change the logo, replace `ikram-logo.png` and `favicon.png` (square, transparent, at least 76×76 px).
